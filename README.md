# Metaverse in Sparta

A **Unity**-based mini-game hub where players explore a main scene and enter various mini-games through interaction.

## About

Players move around the main scene and press `F` to enter different mini-games (Flappy Plane, Dungeon). High scores are tracked and displayed on the main UI.

## Features

- **Main Scene** — Player movement (WASD / arrow keys) with interaction-based entry system
- **Flappy Plane** — Click or spacebar to dodge obstacles and chase high scores
- **Dungeon** — WASD movement + mouse click attacks, wave-based monster combat
- **Score Management** — MasterGameManager collects scores and syncs with main UI (TextMeshPro)
- **Scene Management** — Additive load/unload with Pause/Resume architecture
- **Character Customization** — Equip custom characters via UI menu
